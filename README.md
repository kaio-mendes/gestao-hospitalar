##  Sobre o Projeto

O Sistema de Gestão Hospitalar é uma aplicação web desenvolvida como Trabalho de Conclusão de Curso (TCC) do curso de Análise e Desenvolvimento de Sistemas. O projeto tem como objetivo informatizar e otimizar processos administrativos e operacionais de instituições de saúde, proporcionando maior eficiência no gerenciamento de pacientes, consultas, profissionais e recursos hospitalares.

A solução foi desenvolvida utilizando tecnologias modernas de desenvolvimento web, com foco em desempenho, usabilidade e escalabilidade.

---

##  Objetivos

### Objetivo Geral

Desenvolver um sistema web para auxiliar na gestão hospitalar, centralizando informações e automatizando processos administrativos.

### Objetivos Específicos

* Realizar o cadastro e gerenciamento de pacientes.
* Controlar consultas e atendimentos médicos.
* Gerenciar profissionais da saúde.
* Organizar prontuários eletrônicos.
* Gerar relatórios administrativos.
* Melhorar a comunicação entre setores hospitalares.
* Reduzir erros causados por processos manuais.

##  Instalação

### Clonar o repositório

```bash
git clone https://github.com/seu-usuario/gestao-hospitalar.git
```

### Entrar no diretório

```bash
cd gestao-hospitalar
```

### Instalar dependências

```bash
npm install
```

### Executar projeto

```bash
npm run dev
```

O sistema estará disponível em:

```bash
http://localhost:5173
```
